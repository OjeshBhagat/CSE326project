Your task is to replace the hero video with an image sequence–based scroll animation for a perfectly smooth, Apple-level experience.


---


GOAL:


- Replace video scrubbing with frame-by-frame image rendering

- Scroll controls frame progression

- Achieve ultra-smooth, precise, and cinematic playback

- No lag, no stutter, no video limitations


---


ASSETS:


- Image sequence is stored in a folder (e.g., ./assets/frames/)

- Frames are sequentially named:

  frame_0001.jpg, frame_0002.jpg, ..., frame_XXXX.jpg


---


IMPLEMENTATION APPROACH:


Use a <canvas> element to render frames instead of using <video>.


---


SETUP:


1. Create a hero section with:

   - Height: 200vh–300vh (for scroll space)

   - A sticky canvas container (position: sticky, top: 0)


2. Canvas should:

   - Fill viewport (width: 100%, height: 100vh)

   - Maintain aspect ratio

   - Be centered


---


FRAME LOADING:


- Preload all images into an array:

  const images = []


- Loop through all frame paths and load them

- Ensure images are cached before animation starts


---


SCROLL → FRAME MAPPING:


1. Calculate scroll progress:


progress = (scrollY - sectionTop) / sectionHeight

progress = clamp between 0 and 1


2. Map progress to frame index:


frameIndex = Math.floor(progress * (totalFrames - 1))


---


RENDERING:


- On scroll (or requestAnimationFrame):

  - Draw corresponding image onto canvas:


context.drawImage(images[frameIndex], 0, 0, canvas.width, canvas.height)


---


SMOOTHNESS STRATEGY:


- Use requestAnimationFrame for rendering loop

- Track currentFrame and targetFrame

- Apply LIGHT interpolation:


currentFrame += (targetFrame - currentFrame) * 0.15


- Then render Math.floor(currentFrame)


- If any lag occurs:

  → remove interpolation and use direct frame mapping


---


PERFORMANCE OPTIMIZATION:


- Use requestAnimationFrame (NOT heavy scroll logic)

- Preload images efficiently

- Use properly sized images (not overly large)

- Use devicePixelRatio for crisp rendering


---


VISUAL BEHAVIOR:


- Canvas stays sticky while scrolling

- Frames transition smoothly as user scrolls

- No flicker or frame skipping


---


OPTIONAL POLISH:


- Slight fade-in of canvas on load

- Add subtle overlay text that fades out as scroll progresses

- Keep everything minimal and cinematic


---


REMOVE VIDEO COMPLETELY:


- Remove all video elements and logic

- Replace entirely with canvas-based system


---


OUTPUT REQUIREMENTS:


- Clean HTML + CSS + JavaScript (or React)

- Well-structured and production-ready

- Responsive and performant


---


BEFORE IMPLEMENTING:


- Explain how image sequence rendering works

- Explain why it is smoother than video scrubbing


THEN:


- Build the full scroll-driven image sequence system

- Integrate into hero section


---


FINAL GOAL:


Scroll should feel like controlling a timeline frame-by-frame.


The experience should be ultra-smooth, precise, and cinematic — like an Apple product page.


No lag. No stutter. No compromises.
